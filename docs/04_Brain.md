# Brain — Контекст и знания проекта

Центральный документ для AI-агентов и команды: бизнес-контекст, термины, ограничения и принятые решения.

## 1. Миссия

Помочь продавцам на маркетплейсах принимать решения на основе данных и автоматизировать рутину.

## 2. Ключевые сущности

| Сущность | Описание |
|----------|----------|
| User | Пользователь платформы |
| Shop | Подключённый магазин на маркетплейсе |
| Product | Товар (SKU) с привязкой к карточке МП |
| Order | Заказ с маркетплейса |
| Stock | Остатки по складам |
| Report | Агрегированная аналитика за период |

## 3. Маркетплейсы (приоритет)

1. **Wildberries** — первый интеграционный партнёр
2. **Ozon** — второй этап
3. **Яндекс Маркет** — третий этап

## 4. Принципы продукта

- Данные важнее мнений — показываем метрики, а не «магию»
- Один источник правды — синхронизация с МП, минимум ручного ввода
- Простота MVP — сначала работает, потом красиво
- AI как помощник, не замена — рекомендации с объяснением

## 5. Ограничения для разработки

- Не хранить пароли маркетплейсов в plain text
- Не делать breaking changes API без версионирования
- Все изменения схемы БД — только через миграции
- Документировать решения в `11_Decision_Log.md`
