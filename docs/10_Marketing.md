# Marketing

## 1. Позиционирование

**SellerOS** — умная панель управления для продавцов на Wildberries, Ozon и Яндекс Маркете. Экономьте время, растите продажи.

## 2. Целевая аудитория

### Primary
- Начинающие продавцы на WB (1–100 SKU)
- Нужен простой дашборд без Excel

### Secondary
- SMB с 2–5 магазинами на разных МП
- Агентства, ведущие клиентов

## 3. Ключевые сообщения

1. «Все маркетплейсы в одном окне»
2. «Данные вместо догадок»
3. «AI подскажет, что улучшить в карточке»

## 4. Каналы привлечения

| Канал | Приоритет | Действия |
|-------|-----------|----------|
| SEO / контент | P0 | Блог, гайды по WB/Ozon |
| Telegram | P0 | Канал + чат продавцов |
| YouTube | P1 | Обзоры, кейсы |
| Партнёрства | P1 | Блогеры, курсы по МП |
| Контекстная реклама | P2 | Яндекс Direct после PMF |

## 5. Launch plan (MVP)

1. **Pre-launch:** лендинг + waitlist, 100 email
2. **Alpha:** 5–10 beta-тестеров из Telegram-чатов
3. **Beta:** публичный доступ, Free tier
4. **GA:** платные тарифы, кейсы клиентов

## 6. Контент-план (первый месяц)

- [ ] «Как подключить Wildberries к SellerOS»
- [ ] «5 метрик, которые должен видеть каждый селлер»
- [ ] Сравнение SellerOS vs Excel
- [ ] Кейс: +20% к выручке за месяц

## 7. KPI маркетинга

- Waitlist signups
- Activation rate (подключил магазин за 7 дней)
- Organic traffic
- NPS среди beta-users
