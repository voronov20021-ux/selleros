# Product Requirements Document (PRD)

## 1. Обзор продукта

**Название:** SellerOS  
**Версия документа:** 0.1  
**Дата:** 2026-07-21

### 1.1 Проблема

Продавцы на маркетплейсах (Wildberries, Ozon, Яндекс Маркет и др.) тратят много времени на рутинные операции: управление карточками, анализ продаж, контроль остатков, ценообразование.

### 1.2 Решение

SellerOS — единая платформа для управления продажами на маркетплейсах с аналитикой, автоматизацией и AI-помощником.

### 1.3 Целевая аудитория

- Индивидуальные продавцы (FBO/FBS)
- Малый и средний бизнес с несколькими SKU
- Агентства, ведущие несколько магазинов

## 2. Цели и метрики


| Цель             | Метрика                 | Целевое значение |
| ---------------- | ----------------------- | ---------------- |
| Экономия времени | Часы на рутину в неделю | −50%             |
| Рост выручки     | Средний чек / конверсия | +10%             |
| Удержание        | MAU / DAU               | > 60%            |


## 3. Функциональные требования

### 3.1 MVP

- [ ] Подключение аккаунтов маркетплейсов
- [ ] Дашборд продаж и остатков
- [ ] Импорт/экспорт товаров
- [ ] Базовая аналитика (выручка, заказы, возвраты)

### 3.2 Post-MVP

- [ ] AI-рекомендации по ценам и карточкам
- [ ] Автоматизация ответов на отзывы
- [ ] Мультиаккаунт и роли
- [ ] Интеграции с ERP/1C

## 4. Нефункциональные требования

- **Производительность:** ответ API < 500 ms (p95)
- **Доступность:** 99.5% uptime
- **Безопасность:** шифрование credentials, RBAC
- **Масштабируемость:** горизонтальное масштабирование backend

## 5. Ограничения и допущения

- Первый релиз — только российские маркетплейсы
- Web-first, мобильное приложение — позже
- Язык интерфейса: русский

## 6. Риски


| Риск                        | Вероятность | Влияние | Митигация                        |
| --------------------------- | ----------- | ------- | -------------------------------- |
| Изменение API маркетплейсов | Высокая     | Высокое | Абстракция адаптеров, мониторинг |
| Конкуренция                 | Средняя     | Среднее | Фокус на UX и AI                 |


## 7. Глоссарий

- **SKU** — единица товарного учёта
- **FBO/FBS** — модели fulfillment маркетплейсов
- **MAU** — Monthly Active Users
