# Decision Log

Журнал архитектурных и продуктовых решений. Формат записи — ADR (Architecture Decision Record).

---

## ADR-001: Структура репозитория

**Дата:** 2026-07-21  
**Статус:** Accepted

**Контекст:** Нужна единая структура для backend, docs, тестов и скриптов.

**Решение:** Monorepo с папками `backend/`, `database/`, `docs/`, `tests/`, `prompts/`, `assets/`, `scripts/`.

**Последствия:** Простая навигация, один CI pipeline. Frontend (если появится) — отдельная папка или репозиторий.

---

## ADR-002: Backend framework

**Дата:** 2026-07-21  
**Статус:** Proposed

**Контекст:** Выбор web-фреймворка для API.

**Решение:** FastAPI — async, OpenAPI из коробки, типизация.

**Альтернативы:** Django REST (тяжелее для MVP), Flask (меньше structure).
