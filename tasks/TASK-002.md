# TASK-002

## Название

Создание первого Telegram-бота SellerOS

## Цель

Запустить первого Telegram-бота, который отвечает на команду /start.

## Что должно получиться

Пользователь открывает Telegram.

Пишет:

/start

Получает ответ:

👋 Добро пожаловать в SellerOS!

Это первая рабочая версия продукта.

## Что понадобится

- Python

- aiogram 3

- BotFather

- Telegram Bot Token

- .env

## Критерий готовности

- Бот запускается без ошибок.

- Отвечает на /start.

- Код загружен на GitHub.

- Сделан коммит.
