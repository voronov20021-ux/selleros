### 1. Новый ProxyPool (`backend/wb_engine/proxy_pool.py`)

**Класс `ProxyState`** - состояние одного прокси:
- Rate limiting: 1 запрос в 10 секунд
- Блокировка на 30 минут при 403/429
- Подсчет запросов и блокировок
- Логирование всех операций

**Класс `ProxyPool`** - умный пул прокси:
- Автоматический failover на следующий доступный прокси
- Возвращает ошибку если все прокси заблокированы
- Не делает циклических проверок
- Не делает повторных запросов
- Равномерное распределение нагрузки

## ⚙️ КАК РАБОТАЕТ ProxyPool

### Алгоритм работы:

```python
# 1. Запрос прокси
proxy_dict = proxy_pool.get_next_available()

if proxy_dict is None:
    # Все прокси заблокированы
    raise SourceUnavailable("Все прокси временно недоступны")

# 2. Используем прокси
async with AsyncWBClient(proxies=proxy_dict) as client:
    product = await client.scan(article)

# 3. Обработка результата
if success:
    proxy_pool.mark_success()  # Прокси рабочий
elif status_code in [403, 429]:
    proxy_pool.mark_blocked("403")  # Блокируем на 30 минут
```

### Состояния прокси:

1. **Доступен** - можно использовать
2. **Rate limited** - ждет 10 секунд после последнего использования
3. **Заблокирован** - получил 403/429, ждет 30 минут

### Логирование:

```

⛔ Прокси ...@130.49.95.84:64902 ЗАБЛОКИРОВАН на 30.0 мин (причина: 403)
⛔ ВСЕ ПРОКСИ ВРЕМЕННО НЕДОСТУПНЫ!
```

## 🎯 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ

### Получить статус всех прокси:

```python
status = proxy_pool.get_status()

print(f"Всего: {status['total']}")
print(f"Доступно: {status['available']}")
print(f"Заблокировано: {status['blocked']}")
print(f"Rate limited: {status['rate_limited']}")

for p in status['proxies']:
    print(f"  {p['url']}: {p['available']}")
    print(f"    До разблокировки: {p['seconds_until_available']:.0f} сек")
    print(f"    Запросов: {p['total_requests']}")
    print(f"    Блокировок: {p['total_blocks']}")
```

### Разблокировать все прокси принудительно:

```python

```

3. **Прокси требует whitelist IP**

   - Проверьте настройки в панели провайдера
